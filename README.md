## ▶️ Run Locally

Clone the repository:

```bash
git clone https://github.com/shaiksa123786-dot/ShopEase.git
```

Go to the project:

```bash
cd ShopEase
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```

For web:

```bash
flutter run -d chrome
```

## 🌐 Deployment

The web version is deployed using **Firebase Hosting**.

Build the web application:

```bash
flutter build web
```

Deploy:

```bash
firebase deploy --only hosting
```
