# ShopEase 🛍️

A modern Flutter e-commerce application inspired by popular shopping platforms.

## Features

- 🏠 Home page
- 🛍️ Product categories
- 🔍 Product search
- ❤️ Wishlist
- 🛒 Shopping cart
- 👤 Login & Registration
- 📦 Checkout
- 👤 User profile
- 📱 Responsive design
- 🎨 Modern UI

## Technologies

- Flutter
- Dart
- Provider

## Project

ShopEase is a Flutter-based e-commerce application built as a learning and development project.
